## 🚀 Featured Projects

### 🗺️ [Orchid Island — Land Intelligence Platform](https://github.com/Brahim-semlali)
Proptech platform migrating legacy MapInfo cadastral data (Marrakech Ouest–Mhamid Sud) into **PostGIS**, with a React + Spring Boot map app for zone/parcel exploration, plus a **RAG assistant** (FastAPI + LangChain + pgvector) over 60 scanned urbanism documents.
`Spring Boot` `React` `PostGIS` `FastAPI` `LangChain`

### 🏋️ [S7aFit](https://s7afit-web.fly.dev/login)
SaaS fitness & health-coaching platform with a microservices architecture: LLM-based coaching, food-recognition ML model, and a RandomForestRegressor calorie-prediction API deployed on Fly.io.
`React 19` `Node.js/Express` `FastAPI` `scikit-learn` `PostgreSQL`

### 🩺 [VACTIS — Lab-Physician Relationship System](https://github.com/Brahim-semlali/Vactis-Backend)
Medical laboratory management system tracking prescriber relationships and patient sample history, with role-based dynamic menus and Swagger-documented REST APIs.
`Spring Boot` `React` `JWT` `PostgreSQL`

### 🔐 [life-cycle-token](https://github.com/Brahim-semlali/life-cycle-token)
Bank payment-token lifecycle management portal — issuance, rotation, and blacklisting — with JWT auth and role/permission management.
`React` `Django REST Framework` `JWT`
